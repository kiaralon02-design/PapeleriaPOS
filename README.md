# Papelería Escolar POS

## Descripción del proyecto

El proyecto consiste en desarrollar un sistema de punto de venta (POS) para una papelería escolar, utilizando el lenguaje de programación Java.

El sistema permite registrar productos, consultar y actualizar el inventario, registrar clientes, realizar ventas, seleccionar medios de pago y generar comprobantes de pago.

## Tipos de productos

- **Productos por unidad:** cuadernos, lápices, lapiceros y borradores.
- **Productos por peso:** materiales que se venden según su peso.

## Medios de pago

- Efectivo.
- Tarjeta.

## Funcionalidades principales

- Registrar y consultar productos.
- Actualizar precios y existencias.
- Consultar productos con pocas existencias.
- Registrar y buscar clientes.
- Realizar ventas.
- Validar las compras según la disponibilidad de productos.
- Generar comprobantes de pago.
- Consultar reportes de ventas.
